## 🧪 QA / Release checklist

### Перед тестированием

-  Сборка готова
    
-  Контент загружен
    
-  Аналитика настроена
    
-  Тест-кейсы актуальны
    

### Перед PROD

-  Получено подтверждение клиента
    
-  QA завершён
    
-  Критические баги закрыты
    
-  PROD-конфигурация проверена
    
-  Есть rollback-план
    
-  Ответственные знают время релиза
    

### После релиза

-  Smoke-тест PROD
    
-  Проверена аналитика
    
-  Клиент уведомлён
    
-  Документация обновлена
